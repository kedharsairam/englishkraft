# Data licence — the dictionary content is NOT MIT

The source code in this repository is MIT, as set out in [LICENSE](LICENSE).

The dictionary content shipped inside the app is **not** MIT. It is derived from
the sources below and carries their terms.

## Wiktionary — CC BY-SA 4.0

The glosses, etymology, usage tags and example sentences are derived from
Wiktionary, whose text is licensed
**Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**
(and GFDL).

<https://creativecommons.org/licenses/by-sa/4.0/>

Because this content is share-alike, a distributed copy of the database carries
the same share-alike terms. It cannot be MIT. That is a licence fact, not a
choice, and it is stated here rather than buried.

Attribution: Wiktionary contributors — <https://en.wiktionary.org>

## Open English WordNet — CC BY 4.0

The taxonomy (hypernyms, hyponyms, antonyms, meronyms) is derived from the Open
English WordNet, under the WordNet Licence and **Creative Commons Attribution
4.0 International (CC BY 4.0)**.

<https://github.com/globalwordnet/english-wordnet>

Attribution required to both Princeton WordNet and the Open English WordNet team.

## ECDICT — treated as unresolved

Frequency ranks, Collins star ratings, Oxford 3000 flags and exam tags were
drawn from `skywind3000/ECDICT`. The repository is MIT, but its own README shows
the data is compiled from EDictAZ.txt, the `cdict` RPM, scraped websites and the
BNC corpus — the last of which is not freely redistributable. An MIT licence on
a repository does not relicense data its author compiled.

This is **not yet cleared**. Until it is, ECDICT-derived fields are treated as
unresolved and are not shipped. See `docs/sources.md` for the full reasoning.
